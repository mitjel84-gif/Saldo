Jouw geld. Jouw overzicht.

Via Enable Banking ga je naar je eigen bank om toestemming te geven. BespaarSlim kan daarna je betaaltransacties ophalen, maar geen betalingen uitvoeren.

🏦

1. Beveiligde verbinding instellen

Eenmalig, nadat je de backend hebt gepubliceerd

Je backend-URL wordt alleen lokaal bewaard. Je toegangstoken blijft uitsluitend in deze browsersessie en wordt niet in GitHub opgeslagen. Deel dit token met niemand.

Nog geen backend ingesteld. Zie de meegeleverde handleiding.

2. Kies je bank

Beschikbare banken verschijnen na verbinding
Nog geen gekoppelde betaalrekening.

Hoe werkt dit?

01Maak een persoonlijke backend

Publiceer de meegeleverde Worker en registreer een Enable Banking-app. Dit kan niet veilig met alleen GitHub Pages.

02Bevestig bij je bank

Je wordt doorgestuurd naar de veilige toestemming- en inlogomgeving van je bank.

03Bekijk je uitgaven

Klik op ‘Transacties ophalen’. Je opgehaalde transacties worden in deze browser opgeslagen. Er wordt niets van je rekening afgeschreven.

Dit is een technisch startpakket en nog geen live bankdienst. Zonder een goedgekeurde API-app en ingerichte backend werkt de echte koppeling niet. Deel geen bankwachtwoorden, pincodes of geheime sleutels via GitHub. Gebruik dit voor eigen gebruik; openbare dienstverlening vereist aanvullende beveiliging, privacymaatregelen en mogelijke vergunning-/contractcontroles.
